# App Store / TestFlight 3.1.0

Warm up and cool down with every workout. Add a timed warm-up before and a cool-down after any workout type, 1 to 15 minutes each, with one guided movement per minute. Thirty new dynamic warm-ups, deep stretches and yoga poses join the library, and you can filter exercises and tag your own by workout phase.

Review notes: No account, paid content, public user-generated content or external service is required for core functionality. Data stays on the Mac. App Store/TestFlight builds update through Apple. Optional Spotify control is unchanged from 3.0.0 and off by default. Test: open any workout setup, check Add a warm-up and Add a cool-down, set each slider to 1 minute, then start. The warm-up runs first, then the workout, then the cool-down. Skip warm-up and End cool-down move on early. The completion screen shows the main result with the warm-up and cool-down durations.
