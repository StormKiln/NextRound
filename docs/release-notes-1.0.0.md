# NextRound 1.0.0

NextRound's first 1.0 macOS release brings together EMOM rounds, Countdown workouts, and reusable local workout templates.

- Build EMOM workouts with ordered exercises, rep/time/distance/calorie targets, configurable lead-in and warning sounds, and large round/workout timers.
- Run continuous Countdown workouts with optional exercise lists and completion checkboxes.
- Browse grouped movements, including kettlebell, push-up, plank, squat and rowing exercises, or create custom entries.
- Save, search, load, rename and delete workout templates on your Mac.
- Choose what the red close button does. Active workouts prevent idle sleep until paused, stopped or completed.
- Read the public privacy policy from **Settings → About → Privacy policy**.

## Downloads and updates

Requires an Apple Silicon Mac running macOS 14 or later. GitHub downloads are Developer ID signed and notarized. GitHub copies check for updates in the app; App Store and TestFlight copies use Apple's update channel and exclude the GitHub updater.

Existing GitHub installations can update through **Settings → Updates → Check for Updates → Install and Restart**. Saved templates are retained. GitHub and sandboxed Apple installations use separate app-data locations; switching channels does not migrate templates automatically.

## Privacy and scope

Workouts and templates stay on this Mac. No account, cloud sync or developer-operated analytics is required. See the [privacy policy](https://github.com/StormKiln/NextRound/blob/main/PRIVACY.md) for local storage, support, update requests and Apple services.

Workout history and session recovery are not included. Unsaved drafts and checklist progress do not survive quitting. Targets guide the exercise; EMOM rounds stay fixed at 60 seconds and Countdown checkmarks never shorten the timer. iOS distribution remains planned.

This release publishes GitHub downloads and a TestFlight build. Public Mac App Store availability follows the owner's separate App Review submission and release.
