# NextRound 2.4.0

Find your next routine faster, with clearer library feedback and better keyboard navigation.

- Sort saved workouts and training sessions by Recently added, Name A–Z or Shortest duration. Sorting preserves saved data and stays selected when you clear filters. Unknown durations appear last; time caps remain limits, not predicted finish times.
- Shared filter controls now say Clear library filters, making their effect on both lists explicit.
- When copying, importing, renaming or moving a session hides it behind filters, the app explains what happened and offers an explicit reveal action.
- Removing a session block keeps keyboard focus on a useful control, announces the change, and restores predictable focus with Undo.
- Twenty new mobility, dumbbell and kettlebell exercises bring the catalogue to 303, with equipment, focus areas and editable targets.
- Release workflows retry transient Rust setup failures without weakening pinned versions or validation.

All six workout modes remain available offline. No account is needed. Existing exercises, saved workouts, sessions and results are preserved. GitHub installations update through the signed GitHub updater; App Store/TestFlight installations continue to use Apple distribution.
