# NextRound 2.7.0

Turn a useful session block into your next reusable workout.

- **Save a block as a workout:** name and preview an independent copy from any of the six workout modes. Timing, movements and targets are preserved; session transitions stay with the session. Reveal the saved workout with an explicit shortcut that keeps your draft.
- **Clearer replacement choices:** block and movement positions distinguish repeated names. Choose an occurrence before selecting a replacement, and see which equipment filter applies. Change equipment settings without losing your selection or search.
- **More usable dialogs:** grouped block actions, bounded scrolling and fixed footers keep controls reachable with smaller windows, larger text and visible scrollbars.
- **20 new exercises:** bodyweight, dumbbell and kettlebell additions bring the library to 363. Equipment guidance now explains that filters match types, not weight quantities or bench configurations.

Offline and account-free. Existing saved workouts and history stay unchanged. GitHub builds update through the signed updater; TestFlight and App Store builds update through Apple.
