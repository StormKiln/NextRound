# NextRound 0.4.0 design

User intent: make the existing macOS interface readable and easy to build workouts in; fix release discovery and icon presentation; support optional Countdown exercise checklists; choose and deliver one complementary feature. Selected feature: local saved workout templates for both modes.

## Behavior
Home uses a two-column introduction (copy left, existing artwork right) followed by matching EMOM and Countdown cards with explicit titles. At narrow widths sections stack. Exercise selection groups the complete seed library into accessible collapsible Kettlebell, Push-ups, Planks, Squats, Cardio and Other bodyweight groups; search reveals matching groups.

A shared exercise editor supports library/custom entries, targets, removal and drag handles with keyboard reordering. Targets have a prominent label (5 Reps) beside Set/Edit target. Scheduled EMOM appearances are called rounds, distinct from target repetitions. Fix button focus styling, spacing and responsive Settings navigation at 760×620 and normal desktop sizes.

Countdown accepts 0–100 exercises with existing validations and optional completion checkboxes (default enabled). Display list/targets during workout; check state survives pause/minimize but resets on new/repeat. Checking everything never ends the timer. Timer timing/cue behavior remains unchanged. Native serialized configurations preserve the optional exercises and checklist option; legacy configurations without them remain valid.

Templates store a name and deep-copied validated WorkoutConfig. Save from either setup; Home lists/searches, loads, renames and deletes templates. Loading edits a separate draft; sessions snapshot configuration. Version-1 JSON in app data is atomically persisted on macOS, with browser fallback for development. Bounded records and explicit errors prevent silent loss/overwrite on corrupt or future versions. No history, sync, equipment telemetry, active-session recovery or extra scoring fields; broader #14/#17 stay in backlog.

Automatic updates honor opt-out, direct channel and dismissal. Check at startup, every 15 minutes while visible, and on focus/visibility/online with a one-minute throttle; retry failures on later triggers. Concurrent checks/installations do not race. Availability never interrupts active workouts, and installation remains explicit and guarded. No updater in App Store builds.

Remove the icon's white outer matte/ring, enlarge the dark face, preserve brand mark. macOS exterior corners transparent; iOS/store-compatible asset opaque. Regenerate all distribution icon sizes.
