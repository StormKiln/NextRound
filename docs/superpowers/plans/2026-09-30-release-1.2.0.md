# NextRound 1.2.0 execution plan

Approved specification: epic #74 and #75–79, with carried validation #73. Execute inline, then independent whole-branch review.

## Design
- Separate version-1 workout-history document using the existing atomic native write pattern and serialized browser repository. Existing settings/templates are untouched.
- Each successful start receives a session ID. Completion freezes timestamp, elapsed duration, configuration and countdown checks. Save is idempotent by session ID. Discard is explicit; navigation, quit and update installation protect unresolved results.
- History page lists newest first, opens snapshot details, confirms deletion and loads a copy into setup for repeat. No scores inferred from prescribed targets.
- Optional catalogId is independent of entry id and survives native/config/template round trips. Legacy IDs are not guessed.
- Three regression fixes: cancel order without stale-data rollback; saved feedback tied to saved configuration; distinct picker loading/error/empty states.
