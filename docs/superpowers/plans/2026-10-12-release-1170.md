**Goal:** Ship filtered CSV history export, twenty exercises, two personal-library fixes and two release-tooling fixes.

## Global constraints
- macOS 14+, Apple Silicon, six modes, offline data. No import/cloud/new workout modes.
- Preserve existing IDs, snapshots, notes and saved settings. Formula-safe CSV, notes opt-in, no inferred performance.
- User authorized implementation, protected merge, immutable tag and both publication channels. Execute inline; no repeated approval handoff.
- Physical checks require an unlocked Mac; blocked checks stay explicitly open. Earlier exact-version acceptance remains separate.

## Review focus
- CSV freeze at invocation, failed/stale reads, midnight/filter transitions.
- Spreadsheet formula text with whitespace/control characters, Unicode and embedded newlines.
- Save panel cancellation/write errors, sandbox scope and repeat submissions.
- Draft equality, Escape/nested focus, save failures and external conflicts.
- Catalog identity/counting/units; processing status exact build identity and no accidental upload.
