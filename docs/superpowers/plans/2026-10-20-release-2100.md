# NextRound 2.10.0 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans task by task, with tests before behavior changes and a fresh whole-branch review.

**Goal:** Fill remaining workout slots randomly while preserving chosen entries.
**Architecture:** A pure candidate filter/sampler plus a preview dialog integrated with the shared generator's guarded Undo. Existing library/equipment/favorites stores supply candidates; no persistence changes.
**Tech Stack:** Existing React/TypeScript/Tauri, Vitest, Playwright.
**Spec:** ../specs/2026-10-20-release-2100-design.md

## Global constraints
Preserve existing entries and timing exactly. Total count <=100. No duplicate additions by catalog identity or normalized name. Filters only affect additions. No schema/dependency changes.

## Review focus
- Custom or personal names duplicate bundled movements: exclude normalized matches.
- Async library/equipment/favorite reload invalidates preview rather than applying stale choices.
- Existing workout edits while dialog open cannot be overwritten.
- Interval personal seconds defaults must fit the work phase.
- Footer/actions remain visible at 760×620 and with larger text.
