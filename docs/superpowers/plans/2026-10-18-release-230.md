# NextRound 2.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship saved-session previews, consistent usable UI, reliable library actions, 20 exercises and retry-safe release artifacts.

**Architecture:** Extend existing React dialogs and stored session snapshots. Share presentation patterns without changing storage schemas or timers. Preserve fresh-read validation before actions and separate Apple/GitHub distribution.

**Tech Stack:** React/TypeScript, Zustand, TanStack Query, Tauri/Rust, Playwright/Vitest, GitHub Actions.

**Spec:** Approved GitHub epic https://github.com/StormKiln/NextRound/issues/342 and children #343–349, #341.

## Global Constraints
- macOS 14+, Apple Silicon; offline/no account, six modes unchanged.
- 263 existing exercises preserved; add 20 distinct entries for 283 total.
- Existing snapshots and editor drafts remain unchanged until explicit action.
- UI verification at 760×620 and larger, visible scrollbars, long content, keyboard and nested dialogs.
- Protected merge, immutable v2.3.0, signed/notarized public artifacts, Apple VALID; physical observations recorded separately.

## Review Focus
- Changed/deleted saved records after preview opens must not load stale snapshots.
- Draft cancellation and active runs must survive preview/management actions.
- Shared filters must not turn failed reads into zero-match claims.
- Twenty-block content and nested dialogs keep controls and focus reachable.
- Reruns must retain correct artifact names and consumers without publication bypass.
