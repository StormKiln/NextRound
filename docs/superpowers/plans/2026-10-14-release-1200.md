# NextRound 1.20.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship read-only saved-workout previews and three library usability fixes, then verify GitHub and TestFlight delivery.
**Architecture:** Keep the existing template repository and six-mode snapshots. Add a focused preview dialog with fresh reads and a reviewed-record guard before loading; reuse a small saved-workout details renderer. Keep library feedback and focus corrections scoped to TemplateLibrary.
**Tech Stack:** React, TypeScript, TanStack Query, Tauri, Playwright, Vitest.
**Spec:** Approved epic #248 and children #249–#253 at https://github.com/StormKiln/NextRound/issues/248.

## Global Constraints
macOS only; six existing modes; 143 catalog entries unchanged. No schema changes, new exercises, accounts or cloud services. Preserve drafts, loaded template associations, saved snapshots and preferences. Preview is read-only. All mutations retain existing conflict guards. User explicitly authorized execution, protected merge, tagging and publication; do not repeat approval questions.

## Review Focus
- Fresh record changes between preview and confirmation must never silently load unseen content.
- Async reads completing after dismissal must not reopen UI, steal focus or mutate drafts.
- Long descriptions and optional lists must preserve reachable actions at 760×620.
- Delayed favourite writes must preserve intentional keyboard navigation while still repairing lost focus.
- Filter recovery must distinguish hidden entries from failed writes or removed records.
