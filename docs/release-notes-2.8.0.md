# NextRound 2.8.0

Build a repeated training sequence without rebuilding each block.

- **Repeat session blocks:** select a sequence, choose additional copies and review the resulting timing and targets before appending independent blocks. Source order is preserved; one Undo restores the draft. The 20-block limit is checked before applying.
- **Clearer editing:** name and recovery errors appear beside their fields and are described to assistive technology. Transition labels identify the block number, even when names repeat.
- **Understand recovery:** final-block settings stay visible with an explanation of when they apply. The repeat preview explains that the former final block's recovery becomes active when copies follow it.
- **Consistent dialogs:** a bounded preview and fixed action footer keep controls reachable with small windows, enlarged text and visible scrollbars.
- **Keep editing after a workout:** finished or cancelled standalone workouts no longer block opening or adapting sessions once their results are handled. Pending starts still protect the draft.
- **20 new exercises:** mobility, bodyweight, dumbbell and kettlebell additions bring the library to 383. Every existing exercise record and saved reference is preserved.

Offline and account-free. GitHub builds update through the signed updater; TestFlight and App Store builds update through Apple.
