# NextRound 1.11.0

## Replace one movement

Every workout builder now offers **Replace** beside each exercise. Swap a movement using the existing library, search, focus-area and equipment filters without changing its position or your workout timing. Compatible targets are kept, while unsupported units receive an explained suggestion to review. Ladder keeps its rung schedule; new interval time suggestions fit the work phase.

Undo the last replacement without discarding changes to other movements or workout timing. Undo expires if you edit or remove the replaced movement, replace again, or leave the builder. Saved workout history is unchanged.

## Fixes

- Open equipment settings directly from **Create a workout**, returning to the same preset and exercise count.
- Invalid or unavailable exercise counts receive keyboard focus for correction.
- Closing workout comparisons restores focus to the originating result, with a stable history-heading fallback if it has disappeared.

## Distribution

Apple Silicon Macs running macOS 14 or later. GitHub downloads use the signed NextRound updater; App Store and TestFlight builds receive updates through Apple. No account or new external service is required.
