# App Store 2.4.0

## What's New

Find saved workouts and training sessions by recently added, name or duration. Clearer shared filters and a new reveal action help you find sessions after copying, importing or renaming them. Session-block removal now keeps keyboard focus in a useful place and announces Undo. This release adds 20 exercises, bringing the library to 303, and improves interface consistency.

## Review notes

Offline macOS workout timer/planner. No account, payment or external service is required for core functionality. Six workout modes and complete multi-block training sessions remain available. Local backups and portable routine files are optional. Apple builds use Apple distribution and do not offer GitHub update installation.
