# NextRound 2.1.0

## Find an alternative

Replace a movement with an explained, curated alternative in any standalone workout or session block. Review technique, equipment and target units, then confirm the change. Suggestions respect your filters and workout type. Compatible targets stay; incompatible targets receive an explained suggestion. No load or effort conversions are inferred. Undo restores the replaced slot without discarding other edits.

## Twenty more movements

The library now contains 243 exercises, including twelve new equipment-free movements, four dumbbell movements and four kettlebell movements. Explore yoga holds, prone shoulder raises, push-up and lunge variations, rotational dumbbell work and kettlebell holds, carries and dead-stop swings. Descriptions explain side and repetition conventions; targets remain editable.

## Session reliability

- Changing a movement in actual performance now asks before clearing unsupported values or resetting an invalid round. Compatible values remain available for review, and validation points to the affected row.
- Sessions remain accessible when collections cannot load. Loading and errors are explicit, with retry and protection against saving stale membership.
- Cancelling a session export is neutral; genuine file failures still show an actionable error.
- Deleted collection memberships can be explicitly removed so session collection edits remain usable.
- Conflicting actual-performance records now focus the affected movement.
- Exercise documentation now reflects the current personal library, catalog metadata and snapshot behavior.

Existing workouts, sessions and history retain their captured data. macOS 14 or later on Apple Silicon. No account or new online service is required. GitHub builds update through GitHub; Apple builds update through Apple.
