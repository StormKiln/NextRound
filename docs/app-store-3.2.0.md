# App Store / TestFlight 3.2.0

A workout screen you can read from across the room. The current movement and its description are much larger. The next movement now shows its description, and the Spotify now-playing line is twice the size. Warm-ups now build from dynamic mobility into active movement, and cool-downs focus on deep stretches held for 50 seconds.

Review notes: No account, paid content, public user-generated content or external service is required for core functionality. Data stays on the Mac. App Store/TestFlight builds update through Apple. Optional Spotify control is unchanged from 3.0.0 and off by default.

To test: start any EMOM. The movement name, description and the Next movement panel with its description are shown beside the timer. Then check Add a warm-up and Add a cool-down in any setup, set each to 1 minute, and start. The warm-up says "Move for 45 seconds", and the cool-down says "Hold for 50 seconds".
