# NextRound 2.5.0

Build a training session from several saved workouts in one step.

- Choose saved workouts in a searchable picker with workout-type and favourite filters. Preview each routine, select several, arrange their order and add independent copies as one batch. Undo removes the batch together. Changed or deleted routines require a fresh review before adding.
- Shared library controls now say Search saved library and All collections, making their effect on both workouts and sessions clearer.
- Moving and duplicating session blocks announces their new position and keeps keyboard focus on a useful control. Undo restores predictable focus. Adding a new block and updating an existing block now use distinct instructions and actions.
- Session and actual-performance dropdowns have consistent readable sizing in macOS WebKit. The saved-workout chooser keeps actions visible at the minimum window size and returns focus when cancelled.
- Twenty new mobility, dumbbell and kettlebell movements bring the catalogue to 323. Entries include equipment requirements, focus areas, searchable aliases and editable starting targets.

All six workout modes remain available offline without an account. Existing exercises, workouts, sessions and results are preserved. GitHub installations use the signed GitHub updater; App Store and TestFlight installations use Apple distribution.
