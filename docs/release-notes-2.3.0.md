# NextRound 2.3.0

## Preview your whole session

Inspect a saved training session before opening the editor. Review every block's timing, movements, targets and transitions, with clear explanations for manual waits and uncapped work. Previewing leaves your draft untouched; opening a session asks before replacing an existing draft and checks for saved changes.

## A more consistent library

Workout and session cards now separate primary actions from management commands, keep labels compact and distinguish Delete. Shared filters explain their scope, show match counts and can be cleared beside session results. Failed session refreshes label cached data and prevent stale actions. Long session collection lists scroll while Cancel and Save remain reachable.

## Twenty new exercises

The library now contains 283 movements: ten equipment-free poses/holds, five dumbbell exercises and five kettlebell exercises. New entries include Dolphin, Gate, Warrior III, dumbbell concentration curls, floor triceps extensions, bottoms-up cleans and deck squats. Bench movements clearly require appropriate support. Targets remain editable.

Release retries now retain separate diagnostic artifacts. Existing saved routines, history and preferences keep their data. No account or new service is required. macOS 14+ on Apple Silicon; GitHub builds update through GitHub and Apple builds through Apple.
