# NextRound 1.3.0

Build your next workout using the training history already on your Mac.

- See each catalog exercise's usage count in the exercise picker, derived from retained saved workouts.
- Try **My favorites**, **Try something new**, or **Mix it up** for up to three exercise suggestions. Review and add individually; search and existing selections are respected.
- Find push-ups using common spellings such as “pushups” or “push ups,” and kettlebells using “kettle bell.”
- Repeating from history now prevents duplicate requests and accidental dismissal while loading.
- History actions identify their session for assistive technology.

Usage means inclusion in a saved completed workout, not measured repetitions or verified completion of every movement. Each exercise counts once per session. Custom and older entries without a catalog link are excluded; missing history is explained. Suggestions are local heuristics, not personalized coaching. Existing templates, history and preferences are preserved.

Requires an Apple Silicon Mac running macOS 14 or later. GitHub downloads are signed and notarized and use the GitHub updater. App Store/TestFlight builds use Apple's update channel and exclude that updater. iOS, cloud sync, target-area filtering and full-workout recommendations remain outside this release.
