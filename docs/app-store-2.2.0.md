# App Store metadata — 2.2.0

## What’s New

Compare two saved session attempts side by side. Review planned work and recorded performance, with neutral differences for matching complete prescriptions. Inspect changed or partial sessions separately. Unknown values stay unrecorded and recorded zero remains visible.

Explore 20 new movements, bringing the library to 263: eight equipment-free poses and holds, six dumbbell movements and six kettlebell movements, with technique descriptions and editable targets.

History now handles missing load and failed refreshes more clearly. Singular session counts and nested-dialog Escape navigation are corrected.

## Review notes

No login, sample files, payments, social posting, AI service or regional feature differences. From Home choose Build a session, add workout blocks, run and save the completed result. Repeat the same session and save another result. In History open a session result and select Compare session results. Attempt selectors offer matching complete prescriptions; enable changed/partial inspection to inspect other saved snapshots. Actual performance is optional manual entry, distinct from planned targets. No global winner or medical recommendation is produced. The app works offline; Apple distribution uses Apple's update channel. Use a physical-device recording and screenshots of the submitted build for App Review; browser captures do not replace Apple's requested recording.
