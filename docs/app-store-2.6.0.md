# App Store / TestFlight 2.6.0

## What to test
Open a saved multi-block session, choose Replace across session, select some occurrences and pick a replacement. Review and edit targets, apply, then Undo. Confirm timing and other blocks remain unchanged. Try an incompatible-unit replacement and a Ladder block.

In Choose saved workouts, select a workout, hide it with search, clear filters, preview it and close the preview. Check keyboard focus and reachable actions at a small window size. Browse the 20 additions (343 total) using equipment and focus filters.

## What's new
Replace a movement across selected session blocks with per-block target review and one Undo. Clearer saved-workout filters, dismissible previews, consistent dropdown controls and 20 new exercises.

No sign-in, sample files, payment or online service is required for core functionality. Workout data stays on the Mac. Apple-distributed builds do not offer GitHub updates.
