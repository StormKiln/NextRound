# NextRound 0.3.0

More ways to train, with a larger exercise catalogue and reliable macOS window controls.

- **Countdown workouts:** choose minutes/seconds, lead-in and warnings. Pause, resume, stop or repeat a single uninterrupted timer with no minute-boundary beeps.
- **43 exercises:** includes 20 kettlebell movements, five additional variations each of push-ups, planks and bodyweight squats, and rowing-machine rowing. Exercise descriptions and sources are documented.
- **Exercise targets:** prescribe reps, seconds, metres or calories where appropriate. Push-ups support reps/time; rowing supports time/distance/calories. Custom entries support all four. Targets follow exercise ordering and appear during the workout.
- **Close-button fix:** red-close minimizes to the Dock by default. General Settings can change it to Quit NextRound; quitting an active or paused workout still asks for confirmation. The preference survives relaunch.
- **Dock restoration:** clicking the Dock icon restores a minimized workout window. Timers continue while minimized; normal sleep/interruption safeguards still apply.

## Installation and updates

Apple Silicon Macs on macOS 14 or later. GitHub downloads are Developer ID signed and notarized. Existing 0.2.0 GitHub installs can use Settings → Updates → Check for Updates, then Install and Restart after finishing the workout. Version 0.1.0 needs one manual upgrade. TestFlight copies use Apple's update path.

## Scope

EMOM targets describe work within a fixed 60-second slot; they do not change round length, add sub-round alerts, count repetitions, or read connected equipment. Machine calorie targets use the equipment display rather than estimating energy expenditure. Countdown is a separate workout mode. Drafts/results remain in-session only; saved workouts, history, exercise editing, recommendations and iOS are future work. Update installation restarts the app, discarding unsaved setup.
