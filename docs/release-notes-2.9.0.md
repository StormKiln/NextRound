# NextRound 2.9.0

Adjust recovery throughout a training session in one reviewed edit.

- **Edit session recovery:** choose blocks, set whole recovery seconds and automatic or ready transitions, and review before/after timing. One Undo restores the draft. Final-block settings remain stored for future additions.
- **Reachable controls:** session editor spacing follows the actual footer height, including long feedback and larger text. Recovery dialogs keep actions outside the scrolling content.
- **Clearer validation:** repeat-copy capacity errors are marked on their field. Recovery errors have explicit accessible descriptions and incomplete drafts can be corrected without losing names or movements.
- **Protected editing:** session mutations, navigation, Undo and saving respect active workouts and pending starts/results.
- **20 no-equipment exercises:** squat and calf variations, leg swings, hip airplane, core and crawling movements bring the catalog to 403. Existing exercise records and local data remain unchanged.

Offline and account-free. GitHub builds update through the signed updater; TestFlight/App Store builds update through Apple.
