# NextRound 1.5.0

## Your equipment
Save the equipment you have in **Settings → Equipment**. Exercise browsing and history-based suggestions use the same selection. Before configuration, all equipment is shown; save with nothing checked for known no-equipment exercises only. **Use all equipment** returns to unconfigured selection.

Choose **Show all equipment** in the picker for a temporary override, with missing equipment labeled. The override resets when the picker closes. **Change equipment settings** returns you to the same search and draft. Existing exercises in workouts, templates and history are never removed. Custom entries remain available; their equipment requirements are not assessed. Unknown catalog requirements are excluded from configured filtering unless overridden.

A jump-rated box also satisfies a stable raised surface requirement; a generic surface does not qualify for box jumps. Optional mats are not required equipment. Equipment preferences stay on this Mac, with no new service or account.

## 20 more exercises
The library now includes 63 exercises. New bodyweight movements: glute bridge, mountain climber, dead bug, bird dog, hollow-body hold, superman hold, standing calf raise and inchworm walkout. Eight single-dumbbell options: goblet squat, reverse lunge, Romanian deadlift, single-arm row, floor press, strict press, push press and thruster. Also added: box step-up, box jump, pull-up and medicine-ball slam.

Descriptions clarify unilateral/alternating counts and required equipment. Targets remain editable starting suggestions, not measured performance or individualized coaching. Holds use seconds; other new movements offer repetitions or time. Original catalog identities, saved targets and usage attribution remain intact.

## Fixes
- Long AMRAP circuits follow the current movement when advancing, undoing or wrapping. Scrolling is local to the list and keyboard focus remains on the control. The compact runner keeps progress controls visible, with recording instructions expandable.
- Successful timer reads and controls clear only their respective transient errors. Unrelated save/full-screen failures and native notices remain visible.
- Release notarization has bounded upload and processing time, safe stage logs and retained diagnostics. An ambiguous upload is never automatically repeated.

## Distribution
macOS Apple Silicon. GitHub copies use the signed updater; TestFlight/App Store copies update through Apple. Existing on-device templates/history/preferences remain compatible. Cloud sync, active-session recovery, iOS and App Store approval are outside this release.
