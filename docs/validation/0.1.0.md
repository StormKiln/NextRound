# 0.1.0 validation evidence

## Environment and scope

Local host: Apple Silicon, macOS 26.6.2, Xcode 26.6, Node 24.3.0, Rust 1.98.1. Initial release target: Apple Silicon, macOS 14+. The minimum OS is a declared deployment floor, not a claim of physical testing on every OS version.

## Automated checks

- Core validation/timeline tests: 11 passing, including invalid numeric values, empty/blank exercises, lead-in exclusion, exact boundaries, uneven rotation, and 15 rounds with three movements.
- Native tests: 7 passing, including cue ordering/counts, warning 0/59, zero/short lead-in, pause, interruption, cancellation, immutable configuration, exact native snapshots, and one final completion.
- Browser acceptance: 3 passing for Custom add/reorder/remove, lead-in/round/total clocks, pause/resume, completion/repeat, invalid input, stop confirmation, and draft preservation.
- `make check`: passed locally, including types, source formatting/lint, Rust clippy, tests, and frontend production build.

Tests for the core timeline and native cue rules were run against failing stubs before implementation. Browser flows were run against the empty shell before the UI was added. A selector ambiguity and one HMR-interrupted test run were diagnosed and fixed/re-run; those failures were not treated as product passes.

## Native app and installer

- Built and launched the production Tauri `.app` with approved icon/splash and offline assets.
- Entered native full screen from Start workout and observed the ten-second lead-in with total time held at 15:00.
- Observed round 2 with Push-up and both clocks consistent at 00:01 / 13:01 at 2026-09-29T17:25:56Z during a real 15-minute, three-exercise run.
- Generated the local DMG successfully with `CI=true` after the default Finder-customization packaging path failed. This mode avoids interactive Finder scripting.
- [Native running screenshot](screenshots/native-running.png).

No Developer ID identity was found, and no public release or release tag has been created.
