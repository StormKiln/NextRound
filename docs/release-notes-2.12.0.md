# NextRound 2.12.0

## Swap one suggestion
In **Fill remaining slots**, use **Swap** to replace one unpinned suggestion with a different eligible movement. Your other suggestions, targets, pins and order stay intact. Current equipment, category, focus, intensity and favorites filters still apply. Works in all six workout types and session blocks.

Unpin a movement before swapping it. If the filtered pool has no alternative, the preview stays intact and you can still apply it. Apply adds the reviewed list; Undo restores your original exercises. Pins and swaps last only for this preview.

## Clearer, more reliable dialogs
- A draft changed outside a generation dialog now stays protected until you close and reopen the dialog, even if the draft returns to its earlier values.
- An unavailable suggestion pool no longer marks a valid exercise count as invalid.
- Swap failures appear beside the preview without clearing it or moving focus to the exercise count.
- Pin and Swap actions wrap with consistent spacing. Keyboard focus stays on the replaced slot; fixed dialog actions remain visible at the minimum window size.

## Twenty new movements
The library grows from 423 to 443 exercises. Add variety with alternate-foot, high-knees, boxer-step, lateral, forward/backward, double-under and crossover jump rope; chin-ups, wide-grip and scapular pull-ups, hanging knee and leg raises, bar hangs; kneeling rotational slams, slam-ball burpees and Russian twists; and dumbbell seated presses, single-arm bench presses, walking lunges and front-rack marches.

Every addition includes original technique guidance, equipment and focus metadata, supported targets and editable starting targets. Existing exercise records, saved workouts and results are preserved.
