# NextRound 1.18.0

## Star your exercises

Star bundled or personal movements in the exercise picker. Favourites only combines with search, focus areas and equipment filters. My favorites now uses only movements you explicitly starred, including when workout history is unavailable. Create a workout still lets you choose the exercise count and undo generation without changing your timing.

The previous history-ranked preset is now **Most used**. Try something new and Mix It Up keep their existing behaviour. Stars are local preferences, separate from saved-workout favourites. Archived personal exercises retain their stars for restoration; copies start unstarred.

## Twenty more movements

The library now contains 143 exercises: ten new equipment-free movements, six dumbbell movements and four kettlebell movements. New choices include Cat-cow, hip adduction, high-plank rotations, dumbbell suitcase carry and floor fly, and kettlebell half get-up and low windmill. Holds use time, carries use time or distance, and Ladder continues to require repetitions. Existing exercises and saved snapshots are preserved.

## Library fixes

- Personal exercise search handles name variants such as pushup and push-up consistently with the picker.
- Empty personal search results offer a clear-search action.
- Renaming an exercise out of the current filter returns keyboard focus to search.
- Unreadable or unsavable star preferences show recovery controls without silently replacing stored data. Failed writes keep the existing favourite selection and keyboard focus.
- Compact picker controls leave more room for matching exercises at the minimum window size.

For Apple Silicon Macs on macOS 14 or later. GitHub copies use the signed updater; Apple copies remain managed by TestFlight/App Store. Each distribution channel retains its own local data.
