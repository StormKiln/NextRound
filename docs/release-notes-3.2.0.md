# NextRound 3.2.0

## A workout screen you can read from across the room
The timer stays the same size, and the rest of the screen is now used for what you're doing:
- The current movement's name, target and description are much larger. The description no longer cuts off after a few lines.
- **Next movement** is now a panel that shows the next movement's description as well as its name and target, so you know what's coming before the beep.
- The Spotify now-playing line is about twice the size, with larger artwork.

The workout screen now fits the window height on every workout type. Pause and Stop stay in view, and long text scrolls inside its own panel.

During a warm-up or cool-down change of position, the heading names the next movement and shows its description, so you can get into position before it starts.

## More active warm-ups
Warm-ups now build up:
- About the first third is dynamic mobility, like leg swings, World's greatest stretch and squat-to-stands.
- The rest is active movement to raise your heart rate, like jumping jacks, step jacks, butt kicks, lateral shuffles, bodyweight squats, lunges, glute bridges and bear crawls.

Passive floor and seated drills are no longer used for warm-ups. Each warm-up minute asks you to **move for 45 seconds**. High-intensity and equipment movements stay out of warm-ups.

## Deeper cool-downs
Cool-downs now focus on deep stretches such as pigeon, frog, lizard, couch stretch, half splits and Garland Pose. Each stretch is held for **50 seconds**, leaving 10 seconds to change position. Light and relaxation-only items such as corpse pose, neck and wrist stretches, and legs up the wall are no longer used in cool-downs. They stay in the library.
