# NextRound 1.12.0

## Your saved favourites

Mark saved workouts as favourites and find them again with Favourites only. Combine this with a workout-type filter and name search across EMOM, Countdown, Intervals, AMRAP, For Time and Ladder. Clear filters returns to the full library. Favourites stay on your Mac and are separate from exercise suggestions based on workout history.

## Fixes

- Refresh saved workouts directly when a displayed record has changed or disappeared. Recovery keeps your filters and proposed rename text.
- A stale rename cannot silently overwrite a newer saved name. Refresh to review the current name before confirming again.
- Closing library actions returns keyboard focus to the original control, or the Saved workouts heading when that row disappears after deletion, renaming or unfavouriting.

## Storage and distribution

Existing saved workouts start unfavourited; their names, identities and workout configurations are preserved. Updating or renaming a favourite keeps its status; Save as new creates an independent unfavourited copy. Unsupported or unreadable data is preserved rather than replaced. Older native versions cannot edit documents containing favourite metadata; use 1.12.0 or later after favouriting a workout.

Apple Silicon Macs running macOS 14 or later. GitHub downloads use the signed NextRound updater; App Store and TestFlight builds receive updates through Apple. No account or new external service is required.
