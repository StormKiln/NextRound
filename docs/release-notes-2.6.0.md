# NextRound 2.6.0

Adapt a whole session without editing every block separately.

- **Replace across session:** choose a movement, select its occurrences across blocks, review the replacement and each target, then apply one reversible edit. Compatible targets remain; changed targets are explained and editable. Ladder blocks keep their rep schedule. Saved workouts and past results stay unchanged.
- **Clearer saved-workout selection:** clear chooser filters without losing selected order, see how many selections are hidden, and close an inline preview with predictable keyboard focus.
- **Consistent controls:** session comparison and replacement dropdowns use matching sizing, padding and disclosure indicators. Dialog actions remain reachable at the minimum window size.
- **20 new exercises:** Pilates/core movements plus dumbbell and kettlebell variations bring the catalog to 343. Entries include equipment, focus areas, technique cues and editable targets.

Offline and account-free. All six workout modes and existing local data remain supported. GitHub builds update through the signed updater; TestFlight and App Store builds update through Apple.
