# NextRound 1.21.0

## Portable saved workouts

Export a saved workout to a JSON file and import it on another Mac or share it with a training partner. All six workout types retain their timing, ordered movements, descriptions and targets.

Review the file before adding it to Saved workouts. Imports create independent, unfavourited copies and leave your current setup untouched. Duplicate names receive a suggested copy name for review; existing workouts are never overwritten. Imported personal movements remain workout snapshots rather than being added to My Exercises.

Workout files include custom descriptions, so review those before sharing. They exclude history, workout notes, preferences and favourites; this is not a full backup or history CSV export. Files are limited to 1 MiB and 100 movements.

## Clearer personal exercise management

- Saving an exercise hidden by your current filters explains where it went and offers an explicit reveal action.
- Archive and restore actions announce the exercise name and explain that existing workout copies remain available.
- Exercise summaries distinguish supported units from the default target, using readable labels such as Reps, Seconds, Metres and Calories.

## 20 more movements

The bundled library now includes 163 exercises: 10 additional bodyweight movements, six dumbbell movements and four kettlebell movements. New options include pelvic tilts, gate openers, modified side planks, single-leg Romanian deadlifts, dumbbell rows, step-ups and bottoms-up kettlebell carries. The previous 143 records remain unchanged.

For Apple Silicon Macs running macOS 14 or later. GitHub copies use the signed updater; TestFlight/App Store copies remain Apple-managed.
