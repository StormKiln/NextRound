# NextRound 2.2.0

## Compare two session attempts

Choose two saved session results and inspect planned work and recorded performance side by side. Matching complete prescriptions show neutral differences for matching movements and occurrences. Changed or partial sessions can be inspected without deltas. Missing values remain unrecorded; explicit zero stays visible. Recorded loads are compared consistently across kg and lb, with the normalization explained in the view.

## Twenty more movements

The library now contains 263 exercises. Add eight equipment-free poses and holds, six dumbbell movements and six kettlebell movements: Boat, Chair, Eagle, Happy baby, Sphinx, Locust, Extended side angle, Half moon, Zottman and reverse curls, Arnold press, alternating floor press, kickstand Romanian deadlift, overhead carry, double clean/front squat/jerk, seesaw press, hand-to-hand swing and tactical lunge. Targets remain editable and descriptions explain counting conventions.

## Reliable history and dialogs

- Missing load no longer qualifies as an equal recorded load or a load-qualified best.
- Failed history refreshes clearly label cached data and disable current-data actions until retry succeeds.
- One-block sessions now use singular wording.
- Escape closes only the topmost nested dialog and restores keyboard focus.

Existing saved workouts, sessions and history retain their snapshots. No account or new service is required. macOS 14 or later on Apple Silicon. GitHub builds update through GitHub; Apple builds update through Apple.
