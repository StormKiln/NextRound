# App Store / TestFlight 2.11.0

Pin the random exercise suggestions you like, then reshuffle the remaining slots. Keep your chosen movements, preview the additions and undo with one action. Generation dialogs now share clearer controls and recover correctly from a session-history read failure. Twenty new no-equipment exercises bring the library to 423 movements.

Review notes: No account, paid content, public user-generated content or external service is required for core functionality. Data stays on the Mac. App Store/TestFlight builds update through Apple. Test: open any workout, select Fill remaining slots, preview additions, pin one, reshuffle, apply and Undo. Pins last only for the current preview; filter/count/library changes invalidate it.
