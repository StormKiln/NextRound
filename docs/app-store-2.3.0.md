# App Store 2.3.0

## What's new

Preview a complete saved training session before opening it. Review blocks, exercises, targets and transitions while keeping your current draft safe. Enjoy more consistent library actions, clearer filters and improved scrolling in session collection dialogs. This release also adds 20 exercises, bringing the library to 283, and prevents stale session actions after a failed refresh.

## Review information

No account, sample files or payment are required. On Home, build and save a training session, then choose Preview on its saved card. Scroll through the prescribed blocks and choose Open in editor; an existing session draft requires replacement confirmation. All six workout modes remain available. Data stays local and no external service provides core workout functionality. Distribution and updates use Apple for this build.

Use the updated README production screenshots as product reference; they use sample data and are not physical-device recording evidence. Physical recording, tester access and installed acceptance are recorded separately in release issue #349. Existing privacy policy remains applicable.
