# NextRound 1.24.0

## Find a workout that fits

Choose Available minutes in your saved-workout library and apply a time budget. NextRound includes the lead-in and scheduled rest when matching a workout. For Time and Ladder use a configured time cap; uncapped workouts are excluded while a budget is applied. Caps are not predicted finish times, and pauses can extend your session.

Combine time with your collection, workout type, favourites and search. Invalid edits keep the previous applied filter; Reset time removes just the budget, while Clear filters resets everything. Filter choices stay with you as you navigate during the app session.

## Easier collection transfers

- Export failures are brought into view and focused, even below long collections. Retry a failed initial library read directly in the dialog.
- Import name problems appear beside the affected fields. A fixed Review invalid names action takes you to the first problem without discarding edits.
- Added real-file regression checks for partial writes and sync failures, verifying that the old library survives, temporary files are cleaned up and retry succeeds.

## 20 more exercises

The library grows from 203 to 223 movements: twelve equipment-free core/bodyweight exercises, six dumbbell movements and two kettlebell movements. Additions include Pilates-inspired core work, broad and tuck jumps, dumbbell cleans and jerks, overhead squats/lunges and kettlebell combinations. Each includes original technique cues, equipment/focus metadata and editable targets. Existing exercise identities and saved snapshots are preserved.

## Data and distribution

No storage schema migration is needed. Saved workouts, collections, personal movements, preferences and history stay local. GitHub builds update through the signed GitHub updater; TestFlight and App Store builds update through Apple. This release does not submit App Store review.
