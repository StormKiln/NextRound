# NextRound 2.0.0

## Your whole training session

Build one routine from warm-up to cooldown. Combine up to 20 blocks from EMOM, Countdown, Intervals, AMRAP, For Time and Ladder. Configure recovery between blocks and choose automatic advance or an explicit Ready action. Preview every block’s exercises, targets and timing, then reorder with drag controls or keyboard buttons. Existing standalone workouts remain available.

Save sessions alongside your workouts, mark favourites, organise them into collections, and share independent copies as JSON. Collections can now contain standalone workouts, sessions or both; older collection files remain supported.

## Record your actual performance

Enter optional repetitions, time, distance, calories and load in kg or lb. Actuals remain separate from planned targets. Use whole-block totals or supported movement rounds/rungs, with blank values kept distinct from zero.

History shows one parent session with complete, partial or skipped block outcomes. Review notes, correct actuals, repeat the prescription and export session CSV. Comparisons and recorded bests require matching prescriptions and compatible recorded data; incomplete sessions and missing values are not ranked.

## Recovery and backup

Interrupted multi-part sessions can recover paused at their saved position. Time away is not counted. Review partial work or discard the session explicitly.

Settings now includes full local backup and restore for saved workouts, sessions, exercises, collections, history, actuals and preferences. Preview before replacing data, with a rollback copy and interrupted-restore recovery. Backup files include private data and are not encrypted.

## Reliability and usability

- Clear filters also clears an invalid time-budget draft.
- Checkpoint failures retain recoverable paused work and release keep-awake state.
- Intermediate blocks use a transition cue; the session ending uses the completion cue.
- Resolved session blocks cannot reappear as standalone unsaved results.
- Unsaved notes and actual edits have confirmation protection; write failures preserve entered values.
- Expanded previews, minimum-window spacing, fixed actions and validation focus keep controls reachable.

## Your data and distribution

Existing 1.x data stays in its original stores; 2.0 adds a versioned training store. No account or cloud service is introduced. GitHub builds update through GitHub; TestFlight and App Store builds update through Apple. App Store review submission is separate from this release.
