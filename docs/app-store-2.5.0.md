# App Store 2.5.0

## What's new

Build training sessions faster: search, preview and select several saved workouts, arrange their order, then add them together with Undo. Clearer library labels and block-editing actions make navigation easier. Session and performance dropdowns now have consistent sizing, and keyboard focus stays useful when moving, copying or cancelling. Twenty new exercises bring the library to 323 movements.

## Review information

NextRound is an offline workout planner and timer for macOS. No login, paid content, cloud service or sample file is required. Choose a workout type from Home, set its timing and exercises, and start. For multi-block training, choose Build a training session, then Choose saved workouts to preview and add routines saved in the library. Saved data remains on the Mac. Apple-distributed builds do not use the GitHub updater.
