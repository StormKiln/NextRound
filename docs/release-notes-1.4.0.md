# NextRound 1.4.0

## AMRAP workouts
Build a circuit and repeat it within a fixed time cap. Choose exercise targets, lead-in and warning cues, then record completed movements and partial progress yourself. Complete movement advances the circuit; Undo movement reverses that action. The app counts full circuits as rounds and preserves partial progress in the current exercise's unit instead of combining reps, metres, calories and seconds.

Review and correct progress before saving a completed result. Saved templates and history support AMRAP, including repeating from setup. A target guides your work; the timer does not measure repetitions or automatically advance movements. Progress edits lock when saving is first attempted so a retry cannot change a result that may already be on disk.

## Fixes and improvements
- Stop confirmation pauses the timer and cues while you decide. Keep going restores the prior state; a workout that was already paused remains paused.
- Newly added EMOM movements receive editable starting targets. Existing saved workouts and user-edited targets are preserved.
- Uneven EMOM rotations explain which slots receive extra rounds, or will not run at all. They remain valid workouts.
- Exercise lists scroll independently, keeping add controls outside the list and retaining keyboard/pointer reordering.

## Target defaults
Defaults are simple starting suggestions, not individualized coaching or promises about how quickly a movement can be completed. Adjust target, load and pace to your ability and leave recovery time. Static holds, rowing, suitcase carries and unknown/custom movements start at 30 seconds. Catalog repetitions vary by movement: for example, air squats 10, push-ups 8, burpees 5, swings 12, presses 6–8 and windmills 4. Unilateral targets apply to the chosen side; alternating movements count each repetition. Edit or clear EMOM targets freely. AMRAP requires a target for each circuit movement.

## Distribution and data
macOS Apple Silicon. GitHub copies use the signed updater; TestFlight/App Store copies receive updates through Apple. Existing templates, history and preferences remain on-device. No account, backend or new external service is introduced. Active-session crash recovery and cloud sync are not included. Public App Store approval is separate from GitHub and TestFlight publication.
