# NextRound 1.9.0 — Your movements, ready for next time

- **Personal exercise library:** create your own movements, copy bundled exercises, or explicitly save a workout-local Custom entry for reuse.
- Record category, required equipment, focus areas, supported target units and an optional default target. Personal exercises join the existing picker, search, filters and usage-based suggestions across all six workout modes.
- Edit, archive and restore without changing saved workout or history snapshots. Bundled exercises remain read-only. Duplicate names retain separate identities.
- EMOM and AMRAP ask for a target when a personal exercise has no default. Ladder uses reps-compatible exercises and its own rung targets.
- **Saving fix:** browser saved-workout updates no longer report a false conflict for omitted descriptions or cleared optional targets.
- **Validation fix:** correcting a Custom exercise name clears its old validation message, with the error linked to the input.
- **Search fix:** equivalent Unicode spellings now match consistently in exercise, saved-workout and history searches, while stored text and accents remain intact.

The personal library is local to this installation, with a limit of 500 entries including archived exercises. Archive is reversible; permanent individual deletion and cross-device sync are not included. No accounts, analytics, AI or new external services are introduced. Existing 103 bundled exercises are unchanged. GitHub downloads use the signed updater; Apple-distributed copies continue to update through Apple.
