# NextRound 0.2.0

A more welcoming start, familiar Settings, and an easier way to stay current.

- Start from a new home screen and choose EMOM when you are ready to build a workout.
- Return home without losing the workout setup you are editing during the current session.
- Open a macOS-style Settings modal from the toolbar or **NextRound → Settings… (Command-comma)**.
- View app information and manage update checks in Settings.
- Enjoy the branded splash for at least three seconds, with a clear retry if startup fails.
- GitHub installations can check for signed updates, show download progress, and install/restart on request. Installation is deferred while a workout is running or paused.
- TestFlight and App Store installations continue to receive updates through Apple.

## Installation

Apple Silicon Macs running macOS 14 or later. Open the signed, notarized DMG and drag NextRound to Applications.

**Upgrading from 0.1.0:** install this version manually once. Version 0.1.0 predates the updater; subsequent releases can be installed from Settings in the GitHub-distributed app.

## Current limits

EMOM is the supported workout type. Workout setup and results are not saved across restarts. History, saved workouts, recommendations, other workout modes, Intel Macs and iOS remain outside this release. Update installation restarts the app and discards the current unsaved setup; save any details you need before choosing Install and Restart.
